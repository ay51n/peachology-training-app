# Peachology Learning App

A responsive, browser-based prototype for Peachology learners. It combines a practical entrepreneurship course dashboard, lesson progress, a step-by-step business idea builder, and a lightweight community feed.

## Run locally

Open `index.html` in a browser. The app uses plain HTML, CSS, and JavaScript, so no build step or package installation is needed.

## Deploy to Vercel

This is a static site and can be deployed directly from a GitHub repository:

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Leave the framework preset as **Other**, with no build command and no output directory.
4. Deploy. Vercel serves `index.html` from the project root.

## Prototype notes

- Business Builder fields are saved to the browser's local storage on the final step.
- Course cards, filters, responsive navigation, and community post creation are interactive.
- This front-end prototype does not include accounts, cloud sync, instructor tools, payments, or a back-end database.
